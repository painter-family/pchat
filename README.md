# pchat

Private invite-link chat service.

## Features

- Create a private two-user chat session and share a join link
- Users do not see profile details about each other
- Full chat history remains available for the session
- Upload image/video attachments into the chat
- Delete only your own uploaded media

> The join link is the access credential for the second participant. Keep it private.

## Run

```bash
npm start
```

Open `http://localhost:3000`.

## Test

```bash
npm test
```
